# 이스 IV: 이스의 여명 — 한국어 패치

**→ https://jiseo79.github.io/ys4pce-kr/**

1993년 PC Engine Super CD-ROM² 로 나온 『Ys IV: The Dawn of Ys』의 한국어화입니다.
대사 전체와 엔딩 스태프롤을 번역했고, 한국어 음성 더빙(AI)도 함께 담았습니다.

이 저장소는 **배포 페이지 그 자체**입니다. 패치 파일은
[Releases](https://github.com/jiseo79/ys4pce-kr/releases) 에 있습니다.

---

## 패치하는 법

위 주소에서 **웹 패처**를 여시면 브라우저 안에서 끝납니다. 설치할 것이 없고,
**게임 파일이 서버로 전송되지 않습니다** — 개발자도구(F12)의 네트워크 탭을 켜 두고
확인해 보실 수 있습니다.

준비물은 두 가지입니다.

1. **일본어 원판 CD 이미지** — 가지고 계신 디스크에서 직접 뜨신 것
2. **순정 시스템 카드** `syscard3.pce` — 한글 카드를 만드는 재료입니다

영문 텍스트 번역 패치(`YsIV(US)v95.zip`)가 필요한데, 일본판을 넣으시면
**패처가 그 단계까지 대신해 드립니다.** 영문 *음성 더빙* 패치는 필요 없습니다.

> **한글 시스템 카드 생성은 건너뛰지 마세요.** 한글 글꼴이 CD 가 아니라 시스템
> 카드 쪽에 들어갑니다. 이미지만 패치하고 순정 카드로 실행하면 한글이 보이지
> 않습니다.

> **이미지와 카드는 같은 판올림끼리 쓰셔야 합니다.** 카드 안에 글자 번호표가
> 들어 있고 이미지는 그 번호로 글꼴을 찾습니다. 판올림에서 대사가 늘거나 줄면
> 번호가 밀립니다 — v0.9.2 에서는 45개가 밀렸습니다. 한쪽만 갈아 끼우면
> **오류 없이** 일부 글자가 엉뚱한 글자로 나옵니다.
>
> 웹 패처는 둘을 한 번에 만들어 주므로 신경 쓰지 않으셔도 됩니다.
> xdelta 로 직접 하시는 분만 **이미지 패치와 `syscard` 패치를 둘 다** 받으시면 됩니다.

## 이 저장소에 있는 것

```
index.html      배포 페이지
patcher.html    웹 패처 (알고리즘이 그대로 들어 있습니다 — 읽어 보시라고)
stats.html      이용 집계
assets/         패치 데이터 (텍스트 · 음성 · 시스템 카드 레시피)
links.json      내려받기 주소 — 여기만 고치면 링크가 바뀝니다
checksums.json  체크섬 목록
```

개발에 쓴 도구들(번역 감수기, 더빙 스튜디오, HuC6280 어셈블러·디스어셈블러 등
78개)은 이 저장소에 없습니다. 무엇을 만들었는지는 페이지의 **`08 제작방식 · 도구`**
탭에서 보실 수 있습니다.

## 이용 조건

원본 게임 데이터와 시스템 카드 BIOS 는 **포함되어 있지 않습니다.**

패치 파일을 **다른 곳에 올려 배포하지 말아 주세요.** 판올림이 있을 때 옛 버전을
받으신 분께 알릴 방법이 없어집니다 — v0.9 에 실제로 이미지가 깨지는 결함이
있었습니다. **링크를 공유해 주세요, 파일이 아니라.**

자세한 내용은 [LICENSE.md](LICENSE.md) 를 봐 주세요.
