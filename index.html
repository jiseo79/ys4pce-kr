이 항목들은 대사와 다른 렌더링 경로(반각 폰트)를 씁니다. 한국어로 바꾸려면 게임을 멈추게 할 위험이 큰 별도 개조가 필요해 남겨 두었습니다.

왜 시스템 카드인가

PC엔진의 RAM에는 한글 글꼴이 들어갈 자리가 없습니다. 그래서 글자를 시스템 카드 ROM 안에 넣고 렌더러가 거기서 읽어 오도록 고쳤습니다. 덕분에 게임이 RAM을 어떻게 쓰든 글꼴이 지워지지 않습니다 — 대신 한글 시스템 카드를 만드는 단계가 반드시 필요합니다.

세 가지를 준비하시면 됩니다

모두 저작물이라 이 패치에 담을 수 없습니다. 직접 준비하셔야 합니다.

01
Disc

일본어 원판 CD 이미지

직접 가지고 계신 디스크를 CloneCD 형식으로 덤프하세요 — .img(또는 .bin) + .cue.

덤프 방식이 달라도 됩니다. 패처가 트랙 위치를 스스로 찾아 맞춥니다.

02
Patch

영문 텍스트 번역 패치

NightWolve 님의 YsIV(US)v95.zip. 한글 렌더러가 이 패치의 글꼴 개조 위에 올라가기 때문에 반드시 먼저 적용해야 합니다.

음성 더빙 패치는 필요 없습니다 — 아래 설명을 보세요.

03
BIOS

순정 시스템 카드 syscard3.pce

가지고 계신 순정 Super System Card 3.0 으로 한글 카드를 생성합니다. 이 단계를 건너뛰면 게임 안 글자가 보이지 않습니다.

여기서 만든 카드를 쓰세요. 다른 곳의 한글 시스템 카드로 대체하면 세이브를 직접 불러올 때 대화창이 멈춥니다.

영문 더빙 패치는 받지 않으셔도 됩니다

예전 안내에서는 두 패치를 모두 적용하라고 했지만, 확인해 보니 필요 없었습니다.

116 MB 를 아끼실 수 있습니다

영문 더빙 패치가 바꾸는 것은 음성 데이터 영역뿐입니다 (27,592,431 B 전부가 그 영역 안이고, 밖은 0 바이트). 우리 한국어 음성은 같은 자리를 그대로 덮어쓰므로, 영어 더빙을 거쳐 갈 이유가 없습니다.

오히려 이쪽이 낫습니다 — 저희가 한국어로 교체하지 않은 자투리 클립 85 KB 가 영어가 아니라 일본어로 남습니다.

PATCH.BAT 이 “wasn’t found” 라고 하면

그 배치 파일은 덤프 크기가 771,213,744 · 772,634,352 · 67,420,160 셋 중 하나일 때만 동작합니다. 덤프 방식이 조금만 달라도 거부됩니다 — 저희 일본판 립(772,624,944)도 안 받습니다.

이것 때문에 2단계에서 막히셨다면, 곧 웹 패처가 이 .ppf 를 직접 적용하도록 준비하고 있습니다. 그때는 일본판 원판과 이 zip 만 있으면 한 번에 끝납니다.

패치가 안 될 때

인터넷에서 받은 이미지에서 자주 생깁니다. 원인별 대처는 웹 패처 안에서 바로 확인하실 수 있게 옮겨 두었습니다 — 패처 1단계의 “이미지가 안 맞는다고 나오면” 을 펼쳐 보세요.

패치는 두 단계입니다

둘 중 하나만 하면 게임이 제대로 나오지 않습니다.

01
Disc

CD 이미지에 한국어 넣기

대사·음성이 한국어로 바뀝니다.

02
BIOS

시스템 카드를 한글 카드로

이 단계를 건너뛰면 한글이 화면에 아예 그려지지 않습니다. 한글 글꼴이 카드 쪽에 들어가기 때문입니다 — 이미지만 패치하면 깨진 글자나 빈 칸이 보입니다.

가장 많이 빠뜨리는 부분

이미지만 패치하고 순정 syscard3.pce 그대로 실행하시는 경우가 많습니다. 에뮬레이터의 시스템 카드 설정을 여기서 만든 한글 카드로 바꿔 주셔야 합니다.

웹 패처와 syscard.xdelta 둘 다 이 카드를 만들어 드립니다. 다른 곳에서 구한 한글 시스템 카드로 대체하면 세이브를 직접 불러올 때 대화창이 멈춥니다.

어느 쪽을 원하세요?

갈래는 둘뿐입니다. 준비 과정은 같고 마지막에 고르는 모드만 다릅니다.

원음파

한국어 자막 + 일본어 음성

  1. 일본어 원판을 CloneCD 형식으로 덤프
  2. ysutopia 의 텍스트 번역 패치 적용
  3. 웹 패처에서 텍스트만 — 또는 text-jpvoice.xdelta
  4. 한글 시스템 카드 생성 후 에뮬레이터 설정 변경
풀 더빙

  1. 일본어 원판을 CloneCD 형식으로 덤프
  2. ysutopia 의 텍스트 번역 패치 적용
  3. 웹 패처에서 텍스트 + 음성 — 또는 both-jpvoice.xdelta
  4. 한글 시스템 카드 생성 후 에뮬레이터 설정 변경

영문 음성 더빙 패치는 받지 않으셔도 됩니다 — 준비물 탭에 이유를 적어 두었습니다. 이미 더빙까지 적용된 이미지를 쓰고 계셔도 그대로 동작합니다.

브라우저에서 바로

설치할 것이 없습니다. 파일을 고르면 브라우저 안에서 두 단계가 모두 끝납니다. 원본 립이 달라도 되고, 일본어 음성 베이스도 받아 줍니다.

파일은 서버로 전송되지 않습니다

브라우저 안에서만 읽고 씁니다 — 게임 파일을 올리는 코드가 없습니다. 개발자도구(F12)의 네트워크 탭을 켜 두고 패치해 보시면 직접 확인하실 수 있습니다.

방문 수와 패치 종류만 익명으로 집계합니다. 파일 이름도, 내용도, 해시도, 쿠키도 보내지 않습니다.

웹 패처 열기

크롬 · 엣지 · 웨일에서 열어 주세요. 파일을 디스크로 직접 쓰는 기능이 필요한데 파이어폭스와 사파리에는 아직 없습니다. 지원하지 않는 브라우저면 패처가 시작 전에 알려 드립니다.

패치 파일로 직접 적용 (xdelta)

웹 도구를 쓰고 싶지 않으시면 xdelta 형식도 제공합니다. Delta Patcher 같은 도구로 적용하시면 됩니다.

먼저 알아 두실 것 — 원본이 정확히 일치해야 합니다

xdelta 는 원본 파일 전체의 체크섬을 검사합니다. 한 바이트라도 다르면 거부하고, -f 옵션으로도 통과되지 않습니다. 그래서 아래 세 경우는 xdelta 로는 안 됩니다.

  • 덤프한 립이 다른 경우 — CD 오디오(음악) 트랙이 조금만 달라도 거부됩니다
  • 영문 더빙 패치를 건너뛴 이미지 — 위의 일본어 음성 경로
  • 이미 텍스트를 적용한 이미지에 음성을 덧대는 것 — 둘 다 원하시면 both 하나만

셋 중 하나라도 해당되시면 웹 패처를 쓰세요. 웹 패처는 바뀌는 구간만 덮어쓰는 방식이라 립이 달라도 그대로 동작합니다.

텍스트+음성 내려받기

적용 후 에뮬레이터의 시스템 카드를 한글 카드로 바꾸는 것까지 하셔야 끝입니다. 이미지만 바꾸고 순정 카드로 실행하면 한글이 보이지 않습니다.

v0.9 로 만드신 이미지는 다시 만들어 주세요

패치된 이미지의 섹터 오류정정 데이터(EDC/ECC)를 다시 계산하지 않는 결함이 있었습니다. 이 필드를 검사하는 환경에서 두 가지가 일어납니다.

  • “sector 3667 오류” 같은 읽기 실패 — 오프닝은 나오는데 본 게임이 시작되지 않습니다
  • 더 조용한 쪽: 일부 섹터가 자동 정정되어 원래 영어로 되돌아갑니다 — 오류 없이 잘 도는데 한글이 안 나옵니다

Mesen 은 이 필드를 보지 않아 정상으로 보였고, 그래서 검증을 통과했습니다. Mednafen · RetroArch(Beetle PCE) · 실기 CD-R 에서 문제가 됩니다.

게임 데이터 자체는 v0.9 와 동일합니다 — 데이터 트랙 해시는 바뀌지 않았습니다. 바뀐 것은 각 섹터의 오류정정 필드뿐입니다.

  • 패치가 건드린 모든 섹터의 EDC/ECC 재계산 — 웹 패처 · 패치 파일 · 빌드 전부
  • 원본 자체에 오류정정 데이터가 없는 립(일본판 덤프 다수)도 정상으로 복구합니다
  • 패치 후 EDC/ECC 검증을 추가 — 이 결함이 다시 배포되지 않습니다
  • 데이터트랙 위치 자동 탐지 — 프리갭 처리가 다른 립도 그대로 패치됩니다
  • 일본어 음성 + 한국어 자막 경로 지원 (웹 패처 · 전용 xdelta)
